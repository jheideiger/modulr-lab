produce, transform, control: what a module really does.

video

what does a module do?

In the first two lessons, we looked at sound itself. A signal has a frequency and an amplitude, and it can contain several frequencies whose makeup shapes its timbre.

But in a modular synthesizer, these signals don't stay isolated. They can be produced, transformed, mixed… and used to control other parts of the system. So what does a module actually do?

produce.

To make a sound, you first need a source. An oscillator produces an electrical signal that changes continuously over time. That signal can be a sine, a triangle, a square or a sawtooth, and each of these shapes has a different harmonic makeup: that's what we saw in lesson 2.

The oscillator is therefore a source. It produces something we can then send elsewhere in the system. To hear it on a real module, see the patch note what an oscillator does.

transform.

Producing a signal isn't enough. We may want to modify it: remove some frequencies, keep others, change its level. That's the role of other modules.

A filter acts on the frequency content of the signal: by gradually reducing the high frequencies, it makes the sound darker. The signal produced by the oscillator is still there, but it has been transformed. Other modules act on amplitude: a VCA, for example, lets you control the level of a signal.

combine.

In a modular system, several signals can be combined. You can mix them, compare them, distribute them, or send them to different places in the system. The same signal can thus become the raw material for several different processes.

So the system isn't a fixed chain. It's a set of functions that can be connected in different ways.

control.

There is a third function, and it's especially important in a modular system. Some modules produce signals that aren't meant to be heard directly: they're there to control other modules.

A slow signal can gradually vary an oscillator's frequency. Another can control the amplitude of a sound. An envelope can determine how a sound starts, evolves, then fades away. These control signals change the behavior of the system over time.

functions, not boxes.

Produce, transform, control: these categories aren't closed boxes. A single module can sometimes fulfill several functions. What matters isn't only the module's name — it's what it does with the signal.

In the video, these functions are embodied by the modules of Make Noise's Shared System: the DPO, the Optomix, the modDemix, MATHS and the Wogglebug. MATHS, for example, can serve as an envelope just as well as a slow signal that moves a parameter: one module, several functions.

And this is where the logic of modular really begins. An oscillator produces a signal. That signal goes into a filter. The filter is controlled by another signal, and the amplitude is itself controlled by an envelope. We're no longer just using several modules: we're building a system in which every element can act on the others. The way we connect these functions determines how the system behaves.

what's next?

In the next lesson, we look precisely at these connections. How can one module control another? What is a control signal? And how can a voltage become a musical gesture? That's control voltage.
