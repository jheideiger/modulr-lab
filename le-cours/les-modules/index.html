que fait un module ?

Dans les deux premières leçons, nous avons observé le son lui-même. Un signal possède une fréquence et une amplitude, et il peut contenir plusieurs fréquences dont la composition influence son timbre.

Mais dans un synthétiseur modulaire, ces signaux ne restent pas isolés. Ils peuvent être produits, transformés, mélangés… et utilisés pour contrôler d'autres éléments du système. Alors, que fait réellement un module ?

produire.

Pour fabriquer un son, il faut d'abord une source. Un oscillateur produit un signal électrique qui évolue continuellement dans le temps. Ce signal peut être sinusoïdal, triangulaire, carré ou en dent de scie, et chacune de ces formes possède une composition harmonique différente : c'est ce que nous avons vu dans la leçon 2.

L'oscillateur est donc une source. Il produit quelque chose que l'on peut ensuite envoyer ailleurs dans le système.

transformer.

Produire un signal ne suffit pas. On peut vouloir le modifier : retirer certaines fréquences, en conserver d'autres, changer son niveau. C'est le rôle d'autres modules.

Un filtre agit sur le contenu fréquentiel du signal : en réduisant progressivement les fréquences aiguës, il rend le son plus sombre. Le signal produit par l'oscillateur est toujours là, mais il a été transformé. D'autres modules agissent sur l'amplitude : un VCA, par exemple, permet de contrôler le niveau d'un signal.

combiner.

Dans un système modulaire, plusieurs signaux peuvent être combinés. On peut les mélanger, les comparer, les distribuer, ou les envoyer vers différents endroits du système. Un même signal peut ainsi devenir la matière première de plusieurs traitements différents.

Le système n'est donc pas une chaîne fixe. C'est un ensemble de fonctions que l'on peut connecter de différentes manières.

contrôler.

Il existe une troisième fonction, particulièrement importante dans un système modulaire. Certains modules produisent des signaux qui ne sont pas destinés à être entendus directement : ils servent à contrôler les autres modules.

Un signal lent peut faire varier progressivement la fréquence d'un oscillateur. Un autre peut contrôler l'amplitude d'un son. Une enveloppe peut déterminer comment un son commence, évolue, puis disparaît. Ces signaux de contrôle modifient le comportement du système dans le temps.

des fonctions, pas des cases.

Produire, transformer, contrôler : ces catégories ne sont pas des cases fermées. Un même module peut parfois remplir plusieurs fonctions. Ce qui compte, ce n'est pas seulement le nom du module, c'est ce qu'il fait avec le signal.

Dans la vidéo, ces fonctions sont incarnées par les modules du Shared System de Make Noise : le DPO, l'Optomix, le modDemix, MATHS et le Wogglebug. MATHS, par exemple, peut aussi bien servir d'enveloppe que de signal lent qui fait varier un paramètre : un seul module, plusieurs fonctions.

Et c'est là que commence vraiment la logique du modulaire. Un oscillateur produit un signal. Ce signal entre dans un filtre. Le filtre est contrôlé par un autre signal, et l'amplitude est elle-même contrôlée par une enveloppe. Nous ne sommes plus simplement en train d'utiliser plusieurs modules : nous construisons un système dans lequel chaque élément peut agir sur les autres. La manière dont nous connectons ces fonctions détermine le comportement du système.

et maintenant ?

Dans la prochaine leçon, nous nous intéressons justement à ces connexions. Comment un module peut-il en contrôler un autre ? Qu'est-ce qu'un signal de contrôle ? Et comment une tension peut-elle devenir un geste musical ? C'est le control voltage.
