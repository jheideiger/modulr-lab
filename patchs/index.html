patchs.

Une fiche par vidéo : le schéma, le câblage et ce qu'il faut écouter.

→ principe

La vidéo montre le patch, la fiche permet de le refaire. Chacune suit la même structure : le matériel utilisé, avec un équivalent générique pour chaque module si vous n'avez pas le même système, le schéma aux câbles numérotés, le câblage étape par étape et les réglages de départ.

Vient ensuite la partie qui compte le plus : ce qu'il faut écouter, trois variations, et un exercice à faire seul, sur votre propre système. Le cours pose les notions, les patchs les font pratiquer.
